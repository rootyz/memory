Your expanded studio

Memory now has 20 exercise types in four families: mnemonic techniques, visual & spatial, sequences & numbers, and everyday & reading. Filter by family, star favorites, or use Surprise me. Choose 3, 5, 7 or 10 task units. New sets are randomized; reviews reuse saved challenges.

A mixed session

Complete a reading pair from Today, then one Memory exercise. Meaning and exact wording remain equally represented within reading. Practise the method deliberately, then try it on something you genuinely want to retain.

Know the task

Grid, missing-object and category-list tasks accept any order. Other tasks require the right response at the right cue or position. Some tasks supply questions or tiles; these are labelled as task cues. Extra hints and notes never change the frozen first answer.

Install or update

Publish the app folder over HTTPS, then open it in Safari and add it to the Home Screen as a web app. For an existing installation, export a backup first and update at the same address. Finish active attempts before applying an available update. Check version 3.0.0 and your previous records. v1 and v2 data have migration support; do not import a v3 backup into an older version.

Apple installation instructions

Preserve your practice

Export backups in Settings. Import replaces current data and does not resume active attempts. Keep backups private and out of the hosting folder. Browser storage can be removed; there is no cloud sync.
